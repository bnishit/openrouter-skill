Use this map for “what is new” and capability selection. Before means coverage in this skill before the 2026-11-11 task, not a claim that OpenRouter launched every missing feature recently. The first maintenance pass fixed old paths/install/stream issues but did not perform this capability audit.

Reviewed the relevant feature contracts, migration notes, and limits for the gaps below. Fetching all pages is an inventory/corpus check, not manual review of every SDK method/example or execution of every API. ## Specialized and adjacent capabilities

- **System One / Decisions / Extractions:** `/api/v1/systemone` provides typed questions/answers; the current spec also declares alpha Decisions and Extractions operations. Copy their exact server-relative paths from OpenAPI; do not normalize the unusual alpha paths by guesswork. Verify each endpoint/model's accepted question/media types and probabilities. Alpha extraction is not a drop-in replacement for a validated invoice schema. [Decisions](https://openrouter.ai/docs/api/api-reference/alphadecisions/submit-a-decisions-request.md), [Extractions](https://openrouter.ai/docs/api/api-reference/alphaextractions/submit-an-extractions-request.md).
- **Official developer MCP:** supplies live models, costs, docs, credits and test calls to a coding assistant, authenticated by OAuth. Use it while building; keep app inference on an app-owned API integration. [MCP](https://openrouter.ai/docs/guides/overview/mcp-server.md).
- **Ori:** Harness, Code and Eval are documented as available. Intern and Desktop are waitlisted. Eval can compare models on real task prompts; it does not prove your app’s task flow is correct. Do not replace the user's CLI/login config as part of a skill refresh. [Ori](https://openrouter.ai/docs/guides/ori/overview.md), [Eval](https://openrouter.ai/docs/guides/ori/eval.md).
- **Infrastructure:** Terraform manages administrative resources; Stripe Projects bootstraps integration; SSO/SCIM govern organization/workspace membership. These are discovery/configuration paths, not authorization for this skill to alter billing, secrets, team membership, or workspace policy. [Terraform](https://openrouter.ai/docs/guides/overview/terraform.md), [Stripe Projects](https://openrouter.ai/docs/guides/overview/stripe-projects.md), [SCIM](https://openrouter.ai/docs/guides/features/scim-mappings.md).
- **Classifiers and notifications:** custom task labels, classification market-share API, and notification delivery/settings are adjacent capabilities. Configure only for a concrete product/ops need; a label is a model-derived signal, not a verified business fact. [Classifiers](https://openrouter.ai/docs/guides/features/classifiers.md), [notifications](https://openrouter.ai/docs/guides/features/notifications.md).
- **Zero completion insurance:** qualifying zero-output/error responses do not incur model inference charges, but search, OCR and other auxiliary work can still be billed. An empty UI answer does not by itself establish eligibility. [Policy](https://openrouter.ai/docs/guides/features/zero-completion-insurance.md).

## Capability discovery does not equal implementation

These references teach API choice, request shape, failure handling and limits. Supplied starters still implement selected Chat Completions/image routes only. They do not implement voice/video, Responses/Messages, SDK agent loops, hosted shell, budgets/policies, callbacks, PKCE, workload identity, or admin surfaces. No consuming app or OpenRouter account setting was changed by this audit.

Run `scripts/check_openrouter_docs.py --inventory --strict` to detect added/removed indexed pages and API operations against the reviewed inventory. Run focused checks too. New indexed pages/operations are review leads; unchanged inventory cannot prove unchanged semantics. See [maintenance workflow](docs-check-workflow.md).
